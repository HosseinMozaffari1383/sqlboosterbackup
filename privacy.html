Privacy Policy

Last updated: October 27, 2026

1. Purpose

This application is a private utility used to upload database backup ZIP files from a private Windows server to the owner's Google Drive account for backup and recovery purposes.

2. Google Drive Access

The application uses Google OAuth to obtain authorization to access Google Drive. This access is used only for the database backup functionality described in this policy.

3. Data Use and Sharing

The application uses Google Drive data only as needed to upload database backup files to the designated folder. Google user data is not sold or used for advertising. The application does not share Google user data with third parties except where necessary to provide the backup functionality or comply with applicable law.

4. Data Storage and Security

Backup files are stored in the owner's Google Drive account. Authentication credentials and tokens are managed by the backup software and should be protected against unauthorized access.

5. Retention and Deletion

Backup files remain in Google Drive until the owner deletes them. The owner may revoke the application's Google account access through their Google Account security settings.

6. Changes to This Policy

This policy may be updated when the application's functionality or data practices change. The latest version will be published on this page.

7. Contact

For questions about this policy, contact the administrator through the repository where this page is published.
