# Privacy Policy

**Last updated: October 27, 2026**

## 1. Purpose

This application is a private utility used to upload database backup files to the owner's Google Drive account.

## 2. Google Drive Access

The application uses Google OAuth to obtain authorization to access Google Drive. It uses this access solely to upload database backup ZIP files to a designated folder for backup and recovery purposes.

## 3. Data Use and Sharing

The application does not sell Google user data or use it for advertising. Access to Google Drive is limited to the backup functionality described in this policy. Backup files are stored in the owner's Google Drive account.

## 4. Data Security

The application runs on a private Windows server. Authentication credentials and access tokens are managed by the backup software and should be protected against unauthorized access.

## 5. Data Retention and Deletion

Backup files are retained in the owner's Google Drive until the owner deletes them. The owner can revoke the application's Google access through their Google Account settings.

## 6. Contact

For questions about this policy, please contact the website administrator through the GitHub repository where this policy is published.
