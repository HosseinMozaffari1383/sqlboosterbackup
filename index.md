# Database Backup Utility

This website provides information about a personal utility used to back up a database and store backup files in the owner's Google Drive account.

## Purpose

The utility runs on a private Windows server and uploads database backup ZIP files to Google Drive for backup and recovery purposes.

## Google Drive Access

The utility uses Google OAuth to authorize access to Google Drive. Access is used to upload backup files to a designated folder in the owner's account.

The utility is intended for personal and administrative backup purposes, not for public use.
